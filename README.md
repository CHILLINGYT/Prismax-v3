# prismax
version jugable en modificacion. modelo 3d, animaciones, librerias y mapa 

## Carpetas

- `personaje/` — Leo: base del jugador, transformaciones y su HUD.
- `enemigos/` — enemigos (escenas, scripts, animaciones), sus `modelos/` y `armas/`.
- `npcs/` — ciudadanos, diálogos y navegación; `modelos_mixamo/` con los modelos de peatones.
- `mundo/` — escena del mundo, ciudad, entorno, cielo, agua y casa de Leo.
- `sistemas/` — misiones y eventos.
- `ui/` — menús, ajustes, tema, ícono y videos (intro y fondo).
- `audio/` — música, ambiente y efectos.
- `assets/` — recursos compartidos (texturas generadas, fuentes, iconos de teclas, sonidos de impacto).
- `pruebas/` — pruebas automáticas (ver `pruebas/README.md`).
- `addons/` — plugins de terceros (Terrain3D, Sky3D, Dialogue Manager).
